# Mastermind Worker Bootstrap

## Establish the assignment

Recover the current authorized objective, source refs, workspace, owned write paths,
acceptance test and original return path. Treat a worker and a domain operator as different
responsibilities, not different permission levels. A role name does not authorize spawning,
publishing, deployment, account access or source takeover.

Apply current protected source law and the assigned repository's AGENTS.md. Read only the
relevant Craft common method and one role playbook from the admitted source package.
Do not duplicate all eight roles or copy the parent conversation into the worker.

Read [launch-input.md](references/launch-input.md) when preparing a task.
Read [tools.md](references/tools.md) when selecting or troubleshooting tools.
Read [context-and-returns.md](references/context-and-returns.md) for project facts and memory.

## Prepare before launch

Use the installed existing-owner integration when available:

```bash
pool doctor --mission-ref <assignment-ref> --workspace <exact-workspace> --output <new-observations.json>
pool prepare <launch-input.json> --output <new-packet.json>
pool render <new-packet.json>
```

`doctor` makes bounded harmless reads on the host where it runs. It does not install tools,
copy credentials, prove future provider-native loading, or establish write permission.
`prepare` invokes the existing Craft compiler. `render` rechecks the prepared input and
method identity. These commands do not launch, assign or admit a worker. Missing commands
are capability gaps, not permission to install arbitrary replacements.

Use the existing authorized `pool remote` or Executive path for actual execution. Full
prepared packets require observations for the exact already-selected execution scope.
Do not preselect a different host to make a positive observation fit. Legacy plain-prompt
compatibility supplies method only and explicitly reports project context NOT_SUPPLIED.

## Cold-start the actual worker

Inspect the tools actually exposed in this generation. Separate installation, authentication,
callability, authorization and proven behavior. A server's tool list does not prove a named
write is allowed. Recheck required project facts and source refs before dependent effects.

Use the method on the assignment, not as a new mission. Leaf workers do not spawn helpers.
Operators use only an already-admitted existing child path and conserve the original root,
parent, budget, depth and return obligations. Keep the reviewed adapter identity unchanged.

Do not bypass a denial by changing accounts, paths, tools, models or permissions. Preserve
an uncertain write on its original carrier and reconcile it before retry. Missing optional
inputs can be named as degraded; missing required inputs stop dependent work precisely.

## Return and learn

Return the actual artifact/revision, source/context/method refs consumed, relevant tests
actually run, proof limitations, unresolved effects and next action through the existing
result path. Do not claim the parent consumed or accepted the return merely because it was
sent. Propose durable lessons with evidence to Agent OS; never create a new global writable
memory store or place secrets and private transcripts in launch packets.

A prompt-delivered method is not native Skill attestation. A packaged or installed skill is
not provider loading, organizational permission, successful execution or acceptance.
