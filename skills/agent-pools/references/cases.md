# Native Fabric routing cases

## Stale account table
Input: a local skill says GLM is disabled and names a past account reset date, but
the current router exposes an admitted GLM route.
Use current owner evidence and remove the historical assumptions from the method
through reviewed source. Do not edit credentials, force a provider, or bypass a
real admission refusal. Source correction and installed loading are separate proof.

## Parent is a frontier task, child is a census
Input: the parent is designing architecture, while one child only enumerates exact
files and checks a schema.
Classify that child honestly as mechanical/census; keep consequential judgment at
the principal. Preserve original ancestry and validation requirements.

## Queued or uncertain operation
Input: an Executive operation is queued or a native submission has no response.
Do not send the same work through a second adapter. Inspect/reconcile the original
identity and continue safe independent scope. QUEUED is not STARTED.

## Skill installed, tools absent
Input: a fresh worker can read this skill but no Fabric tool/grant is present.
Report method loaded and launch unavailable for that exact generation. Do not
infer access from installation or create an alternative native child process.
