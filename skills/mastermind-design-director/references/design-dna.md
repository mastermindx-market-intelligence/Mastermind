## Shared core

The user should recognize subject, main assessment and useful next action in a few
seconds. Strong hierarchy compresses complexity while keeping depth available. One
panel answers one question. An optional description is not a quota. Preserve useful
features through named destinations when demoting them from the first view.

Use typography, spacing, luminance and neutral containment. No decorative colored
container edge, stripe or rail. Labeled semantic color and actual chart marks retain
their meanings. A complete visible keyboard focus ring is permitted. Light mode is
its own art direction; locale affects financial direction semantics, not danger.

Never invent a signal, rank, combined score or trade stance for aesthetic decisiveness.
Missing, unavailable, stale, empty and loading are different states. A count requires
its population, time window and coverage. Different observation clocks stay distinct.

## Financial grammar

Question → comparison → interpretation → conditions and evidence. Aligned numerals,
common axes, explicit denominators, honest nulls and meaningful controls support
high density. Preserve data classes without flooding the glance path with internal
mechanics. Explain material caveats beside the number they qualify. Tables have a
purpose and a mobile destination; the whole page must not scroll horizontally.

## Operational grammar

Intent → salient attention → owner and next action → outcome and continuation.
Conversation, a consequential decision and current projects have different weights.
Keep delivered, queued, started, running, completed, reviewed and accepted distinct.
“Projects are moving” requires actual state; an unavailable backend cannot become
plausible decorative activity. Preserve original conversations and effect receipts.

## Current corpus: mixed examples, not approved templates

- OS desktop/mobile: strong intent/decision/projects hierarchy; runtime states,
  keyboard interaction, below-fold behavior and artifact approval remain unproven.
- Sector map: useful comparative marks, denominators and missing values. The original
  mixes a July historical tape with an October fixture while claiming one date.
  Dense mechanism text, a raw route reference and repeated headline count also merit
  careful disclosure work. The canary fixes only the clock contradiction.
- Policy: strong evidence narrative, but “combined” guidance conflicts with an
  unavailable guidance state; activity counts need coverage proof. Preserve these as
  negative annotations rather than reproducing a polished contradiction.

The screenshot manifest records exact Paper IDs, bytes, principles and transfer
limits. All four are AI-curated. No approved/rejected history is invented. Unknown
approval is a research gap, not a reason to manufacture a new approval database.

## Promotion and retrieval

Keep principles, examples and approvals distinct. Approval cites actor, authority,
source receipt, exact version, scope and conditions. A clone inherits no approval.
A new accepted version supersedes an older example only through its existing owner.

The shipped retrieval is deliberately small and deterministic: product/task words
and tags, maximum five examples, with rejected/superseded references excluded.
It is not semantic search and does not claim mature locale/state filtering. Review
applicability manually; use a constrained query and explicit reference IDs when
selection requires finer scope. Add those tags to the existing corpus as it grows.
