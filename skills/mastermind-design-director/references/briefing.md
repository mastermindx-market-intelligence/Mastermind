# Briefing Astra Pro

Start with the user and the desired experience, then preserve real value. A strong
brief gives a designer enough context to make decisions without dictating pixels.
Use a small feature disposition: RETAIN, IMPROVE, RELOCATE with destination, REMOVE
with actual authority, or BLOCKED_DATA. The original assignment remains intact.

**Effective:** “Help an investor see where sector leadership is broadening and whether
the evidence is current. Preserve benchmark/universe/timeframe controls, missing-data
states and the dossier-return path. Study the market map's shared axis and Policy's
honest unknowns; do not reproduce their documented contradictions. Choose a strong
composition. Give the answer visual priority and put mechanics in accessible depth.
Show the assigned desktop/mobile states and explain one meaningful tradeoff.”

**Ineffective:** “Make a stunning dashboard with six identical cards, neon edges,
animated counters and a combined AI score.” It prescribes decoration, invents data
and says nothing about the user's task, preserved functions or evidence.

**Effective refinement:** “The fixture banner claims one date while the historical
tape shows another. On the isolated review copy, name both clocks and preserve all
values, chart geometry, controls and source board. Inspect the actual updated image.”

**Ineffective refinement:** “Simplify everything, modernize it and make it pop.” It
provides neither a defect nor a preservation boundary.

Every assignment includes exact original operation/assignment, source, issue time,
product/persona/question/next action, shell/token references, Paper file/page/nodes,
new-board permission, preservation, states, viewports, acceptance, constraints and
non-goals. Bind a session once known. Creative freedom lives inside that contract.
The digest prevents a return for an older brief from being mistaken for the current one.

Use selected images explicitly. Native Hermes delegation does not guarantee inherited
memory, context files, skill text, browser sessions or successful image forwarding.
Pass the necessary brief/skill references and verify image delivery before review.
The complete templates and three example assignments live with the implementation.
