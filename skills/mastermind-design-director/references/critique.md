# Evidence-bound visual critique

Review sophistication, composition, typography, spacing, distinctiveness, system
consistency, workflow, data readability, accessibility, responsive behavior, technical
feasibility and assignment completeness. Every dimension needs a descriptive rating
and actual evidence. There is no total beauty score.

Record: observed region/state → user consequence → bounded requested change → proof.
Truth, workflow, permission, omitted functionality and material accessibility defects
outweigh taste. A contradictory source claim cannot be averaged away by good spacing.

Astra self-reviews its output. The director reviews product/brand fit and preservation.
Use a vision-qualified specialist for a named unresolved risk, not every adjustment.
A screenshot is evidence of appearance; keyboard/touch/navigation/data correctness
requires the actual relevant consumer. Missing evidence remains `not_observed`.

The helper checks decoded images, digests, exact target and assignment chronology,
full requirement coverage and all twelve dimensions. `candidate_for_design_acceptance`
is only a recommendation. A cited approval still needs canonical verification.

Priorities:
- blocking: false data/authority, wrong target, lost essential function, inaccessible
  required interaction, or uncertain effect; reconcile/fix before acceptance.
- material: meaningful comprehension, flow or visual-system defect; one targeted revision.
- polish: optional preference without a demonstrated task consequence; does not alone
  force another round. Record a conscious tradeoff and stop optional revision.

Bundle changes around one coherent hypothesis. Continue the original session and
assignment; carry the complete original requirements and exact prior critique. Inspect
new screenshots and the affected journey before accepting the revision. Do not treat
one desktop copy improvement as responsive or production qualification.

Keep requests for evidence separate from requests to change a design. An unobserved
dimension does not expand the original task. Gather evidence within its authorized
targets and viewports; record any broader runtime or responsive qualification as a
remaining gap. Do not silently turn a narrow copy refinement into a redesign.
