## Use it

- Dispatch independent ready jobs promptly through the actually available
  Fabric interface, within admitted capacity, budget and source custody.
  Preserve the original root and immediate parent; caller IDs are not auth.
- Give a capable worker a complete bounded wait, fresh-read, repair, test and
  retained-return outcome. A deterministic observer is part of that worker's
  finite task, not a second scheduler or permission grant.
- Keep principal judgment and independent integration moving. Consume each useful
  return without waiting for every sibling.
- Read complete retained bytes and validate the exact result before acceptance.
  Reconcile uncertain effects on the original run/carrier.
- Distinguish source availability, account skill loading, worker START, result,
  acceptance and real consumer proof. A skill does not install a helper, arm
  Executive, grant a background route or wake an idle Web session.

Use the existing active-turn, return-review and closeout owners at their actual
boundaries. No extra independent technical review prerequisite is created.
