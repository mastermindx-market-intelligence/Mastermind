## Confirmed causes, not speculative model psychology

1. **Contradictory entrypoints.** The old account kernel said the principal's job was not to
   code, prohibited one-shot strategic builds and prescribed a twelve-stage program sequence.
   Root files hardcoded a historical CEO model. The account kernel and CLAUDE entrypoint had
   not received all of the execution-first corrections already merged in PR #1321.
2. **Conflicting native delegation instructions.** Repository CLAUDE guidance explicitly
   preferred Sonnet/Haiku native children, while the installed Claude hook prohibits those
   native defaults. The source now defers to existing admitted routing and actual host grants.
3. **Acceptance inflation.** Generic delivery instructions required deployment even for
   source-only/instruction work. The deploy example selected the newest origin/master rather
   than the operation's own merge commit. Acceptance is now scoped to the assigned effect.
4. **False CI-observation state.** The installed PreToolUse hook announces an armed watcher
   before its launch executes. Pre-dispatch inspection cannot prove successful launch or return.
5. **False redundant-poll denials.** The shared hook's five-minute key omits repository and
   query identity. Distinct repositories or distinct PR-status questions can block each other.
   It also cannot know that a first requested read succeeded or that external state is unchanged.
6. **Provider-inappropriate recovery.** A legacy-root compatibility hook denies even diagnosis
   or acquisition and tells Codex to use Claude's EnterWorktree. Historical hook bytes and a
   branch prefix are not, by themselves, an active source writer or a usable provider action.
7. **Stale instruction/memory distribution.** M1, MacBook and two Ubuntu homes carry older,
   differing instruction hashes; remote role blocks still prescribe named executive relays.
   Native memory indexes present dated seat, worker-cap and authority records as standing law.
   Those records must remain evidence, not be silently promoted into current admission.
8. **Broken practical delegation path.** A real read-only review attempt reached the admitted
   Fabric adapter, acquired a lease and then failed support publication with
   `SUPPORT_POLICY_HASH_MISMATCH`. It never became a completed review. The installed Executive
   MCP separately reports readonly mode. Neither fact makes unrelated source work impossible.
