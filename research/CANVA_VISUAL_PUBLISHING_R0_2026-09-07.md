## Connector/runtime limitations discovered

The current Canva connector can list Brand Kits but exposed no Brand Kit creation action. No Brand Kits were visible in the account during R0.

The connector exposes Brand Template search/autofill tools but does not expose a way in the current tool surface to create a Brand Template or retrieve a dataset from an arbitrary newly imported design in the required autofill workflow. Therefore the R0 master template is an editable/copyable Canva design, not yet a production autofill template.

The authorized Remote Desktop Commander device (`Mac-Studio.ts.net lan`) was checked as a possible route to close the Canva-UI gap but was offline during this session, so no browser/UI fallback was available. This is a concrete host-availability limitation, not a claim that web Sol inherently lacks Mac access.
