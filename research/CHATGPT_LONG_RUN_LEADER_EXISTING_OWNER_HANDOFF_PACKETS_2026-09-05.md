One real architecture/research decision with five bounded reasoning responsibilities:

1. product/thesis;
2. systems/authority;
3. research/competitor or evidence;
4. Integrator;
5. Auditor.

Three independent first passes may correspond to the first three roles. No role receives modifying authority merely from its title.

### Explicit non-goals

No routine Pro handoffs/status/polling; no account sharing; no automatic account hopping; no 600-turn quota exhaustion target; no API/Workspace-Agent metered supervisor by default; no shared action authority; no worker implementation before architecture integration; no new priority queue.

### Complete journey

```text
freeze Chairman outcome, current source, decision rubric and five responsibilities

```

### Data and time

Each responsibility has exact source, role, outcome, evidence, mode receipt, start/stop, and current binding. Current quota/capacity remains owner-observed. Wall-clock time is not GPU-hours. No hidden chain-of-thought is stored or exchanged.

### Method

Independent model reasoning, deterministic source/role/capacity envelopes, integrator synthesis, independent audit. The integrated output is evaluated against a preregistered rubric and a control.

### Failure states

Mode unverified; under-duration/non-eligible Pro work; shared answer leakage; duplicate responsibility; conflicting action authority; absent Integrator; Auditor self-review; source moves; capacity exhausted; one role never returns; stale predecessor; context loss; model polling; no downstream consumer.

### Ordered sequence

1. Select one suitable problem and control.
2. Freeze responsibilities/rubric and current sources.
3. Place exact eligible sessions without effect ambiguity.
4. Run independent work.
5. Integrate and audit.
6. Compare with control.
7. Persist decisions and close/park every responsibility.

### Acceptance

No collisions/authority violations; all sessions recoverable; integrated plan improves decision quality or identifies no benefit honestly; low Chairman intervention; no routine Pro waste; explicit capacity and failure evidence.

### Stop condition

One council. Do not fleet-scale before observed value and bottlenecks are known.

### Required return

Responsibility/binding/mode receipts; source and prompts/mandates; independent conclusions; disagreements; integrated plan; audit; rubric comparison; interventions; costs/turns/wall time; closeout; scaling decision.

### Candidate route

Chat-native Sol responsibilities under current Capacity owner. Worker implementation uses Terra/CTO Sol as separately routed. Fable is not the default Meta-CEO or council participant.
