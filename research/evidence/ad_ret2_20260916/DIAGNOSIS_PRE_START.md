   that the existing terminal-read contract is wrong.

   candidate, then calls `ExecutiveOperatorHarnessPort.finish_operator_candidate`.
   Without a candidate, an observed batch never reaches durable evidence.
   Runtime correctly remembers the already-applied start and prevents replay.

   closed terminal role result and stops/completes, or enters failure cleanup.
   The proposed nonterminal fixture wire reaches `OHF_CANDIDATE_RESULT_RECORDED`

   The unchanged terminal wire instead seals and reaches `JOB_COMPLETED`.
   Rejection of an unaccepted wire is correct; the missing capability is a
   separately validated nonterminal branch, not permissive terminal parsing.
4. `executive_worker_broker.py:_ohf_collect_turn` bundles event read, candidate
   and raw role collection under its existing busy gate. The remote adapter
   therefore cannot become nonterminal merely by changing the local port.
   This is source tracing, not a new broker concurrency proof.
