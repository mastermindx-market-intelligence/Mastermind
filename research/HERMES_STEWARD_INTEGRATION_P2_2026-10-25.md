## 4. Host decision after real measurements

**Preferred:** reuse existing self-hosted fleet. Ubuntu1's observed headroom (~54 GiB memory available and 884 GiB disk available, low CPU) comfortably hosts a remote-inference-only headless Hermes challenger; mini1 (16 GiB RAM, 121 GiB free, actual macOS `memory_pressure -Q` ~69% free) is a conditional local Mac desktop/GUI operator. No extra hosting subscription is required. The short Hermes gateway used about **185 MiB RSS** at idle, but this does not bound load peaks, persistent browser/CDP or model contexts. Separate least-privileged OS profile, host admission, backup and uptime instrumentation before production.

**Nous Cloud:** candidate Medium $0.56/day ($16.80/30 running days) and Large $1.09/day ($32.70/30 days), inference/tool calls additional. Keep as a conditional managed remote alternative if self-hosted uptime/network maintenance is demonstrably inferior and exact BYO Z.ai authorization, private MCP, data terms, source pin/customization and billable economics pass. **FlyHermes:** $49/mo (or $39/mo annual prepaid) with 490 credits, but credit-to-GLM task parity, package pinning, plugin/control and transport boundaries unverified; convenience alone does not justify adopting a second service/control plane. No purchase has been made.
