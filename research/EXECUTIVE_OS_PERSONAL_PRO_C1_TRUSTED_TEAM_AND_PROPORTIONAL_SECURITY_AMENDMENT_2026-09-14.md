For C1, fail closed only on a concrete condition that can make the read lane false or unsafe:

1. Slack credential or administrator secret would enter source, chat, argv, environment, logs, or a
   model-visible receipt.
2. Workspace, channel, Relay bot identity, service principal, or installed release does not match the
   admitted configuration.
3. More than one active bot-authored `MMX/SOL_STATE_V1` message exists, or create effect is unknown
   and bounded history reconciliation has not completed.

5. A host mutation has an unknown effect and the same operation has not reconciled it.
6. The change would create a second Runtime, lifecycle owner, publication plane, retry ledger, or

program by default.
