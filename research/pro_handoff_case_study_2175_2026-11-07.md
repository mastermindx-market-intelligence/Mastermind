## Mechanisms worth preserving

1. **True owner, true scope.** The H6 handoff names the incumbent #2175 and paired Macro #10740, root operation, active writer and original runtime/effects. A fresh receiver can work without inventing a second final branch or waiting on a historical chat. The handoff itself does not seize custody.
2. **Source-ready first action.** Exact PRs, commits, failing tests and available inputs make the next operation executable without repeating company-wide archaeology. Check only material newer revisions before editing.
3. **Four-phase ladder with distinct proof.** A = composed source and required checks; B = first lawful primary/tool vertical; C = authoritative account, quota, generation, window, claim/publish and Go-refresh contracts; D = multi-account, worker, reset, OS/browser and broader acceptance. A green component is not B-D.
4. **Progressive acceptance.** The first legitimate primary/tool vertical can advance before every optional pool, UI and worker enhancement, while overall programme completion still requires remaining mandatory rows.
5. **Blocker-to-next-action map.** Live source overlap, pending CI, denied administrative read, unavailable native installation, held worker enrollment and uncertain effects each have a distinct permitted response and a safe independent fallback. Denial or EFFECT_UNKNOWN is never replay authorization.
6. **No artificial gate or redundant labor.** No blanket independent reviewer, old-author approval, duplicate worker, empty CI push or speculative platform limitation. Use focused self-checks, required CI/security rules and true formal approvals only if actually binding.
7. **Sticky capable surface.** Keep a healthy Web Pro session on substantive synthesis/integration when its real tools work. A model label is not tool admission and no prompt changes mode automatically. Use admitted economical workers for separable tasks, without inventing running children.
8. **Checkpoint is not termination.** The instruction is execute -> verify against discriminating proof -> save/read back materially changed facts -> select and **start** the next highest-value lawful phase in the same healthy turn.
9. **Truthful exit.** Only stop for completed bounded scope, genuinely exhausted safe lanes, unresolved modifying effect, actual missing authority, or real session/continuity risk. Preserve a compact source-linked frontier when a genuine boundary occurs.

The differentiator is the pairing of a *concrete next executable phase* with *continuation semantics*. A generic "work for hours" sentence cannot substitute for either.
