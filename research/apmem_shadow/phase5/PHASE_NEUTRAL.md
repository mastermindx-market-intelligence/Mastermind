# Phase-neutral early-turn representation: independent source-robustness experiment

This is an explicitly outcome-guided follow-up after the original phase0/1/2 results showed material grid-alignment sensitivity. It addresses a measurement problem, not a newly tuned risk threshold. The native G0 definition and production emitter remain untouched. A new representation must not masquerade as the original grey dot or treat correlated phase votes as independent evidence.

Use the already computed settled native grey-dot event series for all three fixed dataset-anchored grids. Do not recompute indicators or select a favorable phase. Four fixed comparisons:

1. Original phase0 (retained baseline; no rerun unless needed for exact curve binding).
2. Any-phase onset: a settled dot in any phase on the current session, with the original three-absent-session event convention.
3. Two-phase recent confirmation: at least two distinct phases each observed a settled dot within the latest six sessions; event is the first observation after three absent observations of that condition. Earliest fill is next close, never retroactively at the first phase's dot.
4. All-phase recent confirmation: same six-session memory, all three phases. This is a declared stronger-filter control, not independent-vote confidence.

Each new event representation is evaluated unfiltered, with the existing market-repair context, and with repair plus declining-new-low pressure. Context selects detector onset events; it does not invent later entry events or backdate confirmation. Original phase0/1/2 portfolios are also combined as equal initial-capital sleeves, with no weight optimization, to distinguish signal fusion from merely averaging strategies.

Fixed21/63-session holds,5/20bp fees, next-close execution, no leverage, no stops or profit targets, and the same independent nine-sector sleeves. Evaluate2007-2019 and the independently reset2025-06-05-to2026-11-09 segment. Apply the same fixed detector to2001-2006 as a separate earlier-era falsifier; do not read the reserved2020-May2023 interval. Preserve all arms, event/date counts, exposures, return, Sharpe, drawdown and costs. Check invariance to permutation of phase labels and strict no-future-prefix behavior. Consensus is a different observed pattern, not a calibrated probability.

No new risk threshold, model, parameter search or live promotion is allowed by this experiment. A positive result would justify a separate forward challenger only; a negative result means averaging/confirming the same price-derived oscillator did not solve the economic problem. The purpose is to determine whether calendar-phase noise is a removable source of fragility before demanding more external confluence.
