# Pre-outcome implementation clarifications

Recorded before phase3 market-outcome comparisons. This preserves PROTOCOL.md and adds explicit engineering/economic semantics, not an outcome-selected threshold search.

1. Native replay acceleration: an optional necessary-condition sieve evaluates the exact native 3D not-topped primitives on each prefix. All native T1/T2 paths require that condition. When native veto hysteresis is active the sieve is disabled; no configuration is changed. Sieve-excluded rows report native_decision_computed=false rather than inventing the full gate payload. Potentially eligible rows run the unchanged native gate code with the last-marker analyze projection. Native admission/clock parity is tested on deterministic real and synthetic prefixes. Unknown observations cannot count toward three consecutive absent observations. Three pre-start observations initialize onset state.

2. Price basis: native oscillators receive a causal total-return close index built from the same provider's raw closes, known split factors and cash dividends. This is a declared native-code research input, not a claim of reproducing every historical live board's vendor-adjusted basis. An existing full vendor panel may cover an additional day; it is truncated explicitly to the frozen experiment cutoff without changing its original receipt. Future adjustments cannot alter earlier derived values.

3. Data quality: compare vendor adjustment-factor changes with declared split/cash actions solely as a diagnostic, never a predictor. An absolute log-factor discrepancy above 0.005 quarantines the instrument for an unexplained entitlement/action basis. Selected instruments are not replaced. Internal missing exchange sessions and non-session rows are reported and prevent complete-path claims; no price interpolation or zero-return filling. Complete-current-source receipt is not original historical-publication proof.

4. Conditional payoff is not synonymous with stop avoidance. In the risk-model experiment retain the full stop/target/timeout distribution. A separately labelled fixed economic projection combines predicted class probabilities with each class's mean actual executed return from matured TRAINING events only, less the declared round-trip cost. Gap-through-stop returns are retained in those empirical payoff means; no guarantee of a -5% maximum loss is assumed. The fixed positive-expected-net-payoff selection arm uses a zero cutoff, unchanged capital constraints and deterministic ordering; it is not an optimizer or a fresh live decision authority. Report a stop-probability-only ordering as a diagnostic against this payoff-aware ordering, never as a claimed winner by construction.

5. Distinct durations remain distinct contracts. The 21-session barrier race is a swing-entry measurement. The 63-session no-fixed-profit-cap trend arm is a separate payoff design and cannot inherit 21-session classifier calibration. Compare holding occupancy, foregone winners, repeat stop-outs, mean win/loss and opportunity cost. If a system merely holds more cash or stops participating, report that mechanism rather than attributing it to forecast alpha.

6. Scope remains finite: primary 64 identifier-hash-selected stocks, the declared eleven ETF transfer names and the explicitly separate three diagnostic symbols. New strategies or adaptive thresholds after inspecting results require their own labelled extension; all first-pass arms remain in evidence. No current production ranking, sizing, position, order, router, scheduler or peer-waiver setting is changed.
