# Amendment 6: conditional responses, not a single shared indicator equation

The first chronological models shared continuous feature slopes and allowed regularized group/family/name intercepts. Their failure to establish incremental cohort value does NOT test every personalized response mechanism Chris proposed. Nor does a binary profitable/unprofitable target measure payoff magnitude. These are specific model limitations, not permission to claim an edge or search unlimited alternatives.

After inspecting the primary null results, freeze one bounded model extension:
- Reuse the original event tape, exact mature-label clocks, source data, validation exclusions and 63-business-day fit cadence.
- Add the prespecified short relative improvement, repair-state and paired-calendar slow-support features from the already dated amendments.
- Compare the original shared-coefficient feature model with a group/family-response model. The latter adds stronger-ridge-penalized deviations for a fixed small set of slow/cohort/relative features by economic group and by entry family. Add only three prespecified interactions with measured personality (long-run realized variability, path efficiency, and market beta). Do not create a fitted threshold per stock or select the winning family after its return.
- Evaluate positive net return, cohort-relative success and low preservation separately. Also evaluate a continuous target, log(1+net return), using fixed-ridge conditional mean regression, so a high upside/low-frequency opportunity is not judged only by its win rate. Report exact untrimmed test payoffs and losses; no test outcome winsorization.
- Training standardization, imputations, group levels and regressions use earlier fully matured outcomes only. Exposed MCD 2026 remains excluded. High-dimensional deviations are shrunk toward the shared model. No hyperparameter search or retrospective ticker-specific rule selection.
- Compare losses within dates and named cohorts and preserve all adverse results. This is post-primary exploratory development, not independent holdout validation and not a trading-probability calibration claim.

This is a research-only extension on the existing source carrier. It does not replace the prior results, change production entry authority, or turn a favorable MCD narrative into training data.
