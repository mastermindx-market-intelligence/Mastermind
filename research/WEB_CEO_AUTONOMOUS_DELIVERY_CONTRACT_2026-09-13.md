## 1. Central decision

Build an autonomous mission system led by Web Sol, not a browser-session farm.

Three cooperating loops supply different capabilities:

| Loop | Reasoner/owner | Duty |
|---|---|---|
| Strategic judgment | Current Web Sol, or another separately admitted executive carrier | Recover intent; research; freeze architecture; settle consequential trade-offs; establish a bounded delivery interval; accept work where Sol judgment is required. |
| Operational judgment | Current qualified native COO/principal through its existing harness | Decompose within that interval; direct economical workers; resolve in-scope engineering choices; commission independent review; issue permitted repair; integrate results; return genuine strategic questions. |
| Execution and recovery | Existing Executive/Capacity/Dialogue/Wake services | Enforce grants, exact identity, claims, dependencies, result custody, outstanding effects and recovery. Invoke an operational reasoner only when there is actual judgment to perform. |

The frontend is the common window onto these loops, not a fourth controller. The native principal is replaceable too: a long-running Fable process is useful but not the organizational durability guarantee.

**Web availability must not be necessary for every operational decision.** One productive frontier turn should authorize a coherent interval and foreseeable contingencies. It must not merely originate a set of children that then require the literal next word CONTINUE from the original Web tab.

Two promises stay separate: (a) autonomous delivery under an admitted mission, and (b) automatic invocation of an exact personal ChatGPT Web Pro model. The first is the main implementation objective. The second is a platform/model/permission/identity capability to qualify, not something inferred from an MCP connection or a saved handoff.

If an unanticipated decision is reserved exclusively to an unavailable Web carrier, it must wait or receive a separately authorized decision-owner/carrier change. Independent admitted work continues. No implicit API CEO, sister-Sol promotion, account rotation, or Fable strategic takeover follows.
