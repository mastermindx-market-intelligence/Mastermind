## What materially changed

The original report's central recommendation was sound, but its census understated existing implementation. MRI already has official-actual receipts, correction candidates, same-release-vintage reconstruction, a release composer, publication artifacts and tests. This revision makes those the starting point.

The audit also found an existing display-only expectation calculation that mixes a nowcast with prediction-market values, and a static mismatch between the release publisher and an event-window reader. The plan now specifies a compatibility migration and actual producer-to-consumer proof.

The economic model now separates:

- Official observations, revisions and corrections.
- Economist consensus, point-forecast disagreement and subjective uncertainty.
- Model nowcasts and conditional central-bank projections.
- Futures-implied means, methodology-implied policy probabilities and option-implied densities.
- Pre-event information, observed repricing and separately tested forward implications.

The validation plan now prevents post-event regime contamination, distinguishes historical public reconstruction from actual system replay, requires meaningful source and correction evidence, and treats leaked inputs as invalid regardless of their performance.

The source plan includes a comparative consensus qualification for LSEG and Trading Economics, publication-era limits for public surveys, a qualified direct-source actuals route, and the SF Fed USMPD benchmark. It does not treat marketing claims, public access or a historical data range as proof of complete event-time history.
