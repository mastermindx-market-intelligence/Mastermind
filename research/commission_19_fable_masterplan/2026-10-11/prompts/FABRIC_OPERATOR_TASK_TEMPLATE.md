# Fabric operator task template

This is an authoring template, not a runnable admission request. Populate only fields supported by the actual existing operator action. No task is dispatched by opening this file.

**Current parent and task:** exact native Opus/Fable parent, C19 package and incumbent operation/carrier. Preserve original root/grant lineage. Use a real assigned source workspace, not a copied arbitrary root.

**MISSION:** one independently testable outcome.

**WHY / USER AND MACHINE RESULT:** what becomes possible when this task is accepted.

**EXACT SOURCE / ACCEPTED INPUTS:** repository, full base commit, owned paths and relevant interfaces; original artifacts and DO_NOT_REDO. Refresh only material source/custody invalidators.

**SCOPE / NON-GOALS:** exact edits, tools, data classes and permitted effects. No implicit deployment, source-rights expansion, account change, new spend or portfolio authority.

**FROZEN CONTRACT:** temporal view and clock precision, identity, units/fiscal/basis, missingness, correction ancestry, rights/use, authority and required consumer. Resolve a materially ambiguous contract with the coordinator before changing its meaning, not every ordinary reversible implementation choice.

**EXECUTION CHOICE:** do the task directly when bounded and economical. Spawn workers only for separable qualified work via an observed permitted mechanism. Workers get a subset of this envelope, never independent budget or source-writer authority. Keep shared files under one writer.

**TESTS / EVIDENCE:** exact positive case, hostile cases and source/real-consumer acceptance needed. Keep test counts tied to commands, source SHA, result and scope. Do not open protected outcomes to improve a fixture.

**DELIVERY:** permitted branch/PR/artifact boundary and existing return destination. Do not merge/release merely because a worker says tests pass.

**FAILURE / EFFECTS:** reconcile interrupted modifying calls on the original carrier. No blind retry, alternate-host replay or new key. A real denial stops that effect. A lost response does not prove effect-none.

**RETURN:** STATUS; RESULT; EVIDENCE; GAPS; DEVIATIONS; exact source/custody/effect state; worker returns; next action. Summary normally 250-600 words plus artifact refs; include any decisive counterexample even when longer.

**NOT DONE UNLESS:** the stated capability is independently evidenced or the exact external gate is documented, all child work is reconciled, and the parent can continue without rereading raw history.
