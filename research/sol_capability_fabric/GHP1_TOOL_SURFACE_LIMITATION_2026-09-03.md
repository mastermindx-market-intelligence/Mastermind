# GHP1 Tool-Surface Limitation

The active connected GitHub surface safely creates new UTF-8 files but updating an existing file requires its exact current blob SHA. During this source-candidate turn, connector read results were not available to the reasoning surface for extracting those SHAs. Existing small records were therefore not rewritten merely to make their numeric path lists agree.

Canonical GitHub changed-path truth wins. A repository-native reviewer must consolidate or delete redundant candidate records on this same carrier before source acceptance. This is a source-quality blocker, not authority to create another branch, PR or operation.
