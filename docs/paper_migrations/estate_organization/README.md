## Naming and authority model

Use product name first for working design files; make Reference, Recovery, Test and Legacy roles explicit. Within substantial files prefer Start here / Product / States & user help / Build / History. Do not rename an unexplained abbreviation by guessing.

- **Working design:** navigation entry to current design activity; not automatically approved to build.
- **Build reference:** an exact scope-specific source selection supported by its existing acceptance evidence.
- **Reference:** useful retained patterns, states or earlier designs with purpose stated.
- **Superseded:** an exact successor exists and the relevant preservation comparison is closed.
- **Recovery:** retained snapshot, excluded from normal build entry; do not prune.
- **Test:** verified tooling/canary scaffold, excluded from normal product use.
