## Reproducible source artifact

`scripts/package_mastermind_specialists.py` reads only the closed text-file census
from one full immutable local Git commit. It rejects noncommit refs, missing or
extra input, symlinks/nonregular files, bad UTF-8 and size/path violations. It
ignores uncommitted working-tree replacements. Output is deterministic and created
exclusively, with exact per-file digests and readback.

```sh
python3 scripts/package_mastermind_specialists.py \
  --source-sha <reviewed-exact-commit> --output <new-specialists.zip>
```

Default distribution has five specialists. `--include-native-routing` adds the
replacement `agent-pools` method for eligible native-parent pilots only. Never
publish that compatibility method to Web as permission for shell worker handoffs.
The two native manifests are projections of one package identity; no MCP, hook,
app binding, provider configuration or permission request is included.
`BUILD.json` says PACKAGED_NOT_INSTALLED, native_skill_attested=false and
execution_authority=false. It is artifact provenance, not a capability registry.
