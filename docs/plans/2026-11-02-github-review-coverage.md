## Initial model and publication decision

Use a fresh, genuinely independent qualified semantic reviewer for substantive changes. GLM-5.3 is a provisional default; Grok is a different-family adversarial candidate; MiniMax competes on the same measured quality set. Flash is initially triage and narrowly qualified low-risk review. Actual enrollment, current capacity, requested-versus-served model, budget and author-pool exclusions control selection.

The existing publisher maps PASS to COMMENT and does not expose APPROVE. This extension does not silently change that contract. A genuine eligible non-author must submit any required formal approval; CI and the existing merge owner continue to enforce release. A fully automated approval policy requires separately reviewed provenance/coverage/quality qualification.
