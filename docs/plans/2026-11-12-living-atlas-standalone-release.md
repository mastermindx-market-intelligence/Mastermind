## Material limits
The managed test browser disabled WebGL (GL_VENDOR/GL_RENDERER reported Disabled). The browser evidence therefore proves the shared 3D Canvas compatibility path and application workflows, not GPU shader output, 60 fps, exact WebGL pixel parity, physical-phone performance, or maximum-concurrency scalability.

The WebGL renderer is implemented with instancing, typed-array buffers, cached topology, pixel-ratio caps and lifecycle cleanup. GPU-enabled device profiling remains the next graphics proof. Compatibility rendering has a 30 Hz scheduling ceiling; this is not a measured 30 fps guarantee.

No actual Mastermind sessions, tool calls, repository writes, terminal processes, browser tabs or filesystem moves are connected. The host boundary accepts snapshots; a live adapter still needs authorized acquisition, source timestamps, ordering/gap semantics and a real original-target navigation round trip. Imported/host observations do not acquire invented work motion merely because their source says CURRENT.
