## Engineering decision
Use Three.js WebGL2 for a genuine three-dimensional scene, with native HTML controls and inspector. One perspective camera smoothly changes framing/FOV/elevation between estate and follow views. Cache static point/strand geometry and update bounded creature/probe geometry. Do not build a physics engine, new telemetry lifecycle, event broker, agent runtime or session database.

Richness reflects both role and selected detail. CEO/COO bodies have distinct silhouettes; helper bodies remain individually active, clickable and legible. Source relationships remain explicit; decorative webs imply no semantic relation.

Inputs are deterministic demonstration observations or validated local presentation snapshots. Imported data is labeled imported, even if an embedded field claims current. Future live host adapters supply authenticated source data through existing owners.
