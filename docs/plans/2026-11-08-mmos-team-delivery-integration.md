## Architecture direction

Mastermind OS is the unified human workspace and projection of existing owners. Permanent bot identity, organizational role, provider/model, execution engine, host, project, session and admitted job are distinct entities.

Hermes supplies persistent bot context and collaboration through its existing integration. Project owners retain mission continuity through Agent OS. T3 Code supplies the coding workbench and its own coding-session experience. DeepSeek Harness supplies qualified execution through the supported adapter path. Capacity Fabric and Executive retain suitability, admission, placement, leases, budgets and canonical job lifecycle.

Use the existing authenticated server and host adapters. A web browser must not call a fleet host's localhost, receive provider credentials or gain arbitrary SSH-command authority. No new gateway, identity store, retry engine, autonomous queue, memory plane or credential island is introduced.
