# Mastermind Reality R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a production-inert, skills-only `mastermind-reality` package that teaches an authorized web specialist to inspect one approved Mastermind product journey, consume actual image bytes, correlate semantic and runtime evidence, exercise negative controls, and return a closed evidence record without creating another browser, evidence, lifecycle, identity, authorization, or control plane.

**Architecture:** Reality is an orchestration skill over existing browser, trace, observability, artifact-retention, Executive OS, Agent OS, GitHub, Linear, and Slack owners. A closed JSON Schema carries target, source relationship, capture window, screenshot-byte consumption, semantic/runtime evidence, inference, unknowns, controls, limitations, and the exact next owner. A package-local catalog fragment is input to the single shared package integration owner; this source child does not edit the global marketplace or the closed BSC-P1 validator.

**Tech Stack:** Codex skills-only plugin manifest JSON, Markdown skill/reference documents, JSON Schema Draft 2020-12, Python 3.12+ contract tests with `pytest` and `jsonschema`, and existing browser/trace/observability providers for installed real-path proof.

**Spec:** Chairman-delivered `HANDOFF_C_REALITY.md`, September 7, 2026. The implementation is carried by Mastermind PR #535.
