## Wave E1 — one operator boot/snapshot composition

**Goal:** eliminate repetitive broad archaeology at the start of every session.

Extend an existing Executive Steward / Control Room / CEO boot composition to emit one closed, source-attributed operator packet with:

```text
protected procedure/source
mission identities when available
Executive lifecycle summary + health
Agent OS responsibility/decision summary + health
GitHub current source/PR coverage
Linear projection freshness
Dialogue/Wake continuity state
RuntimeBinding/Web-Sol realm/session state
host/capacity eligibility summary
selected-project Workbench availability
unresolved effects / blockers
```

Rules:

- no new persistence database;
- every row keeps canonical owner/source/freshness/coverage;
- missing source is `UNKNOWN`/`UNAVAILABLE`, not zero/clear;
- packet is bounded and role-filtered;
- no transcript, cookie, credential, private argv/env or arbitrary browser content.

Acceptance: a fresh Web CEO can answer “what is happening, what is blocked, where should I look next?” from the packet and then perform only one or two owner-native reads for the active mission.

## Wave W1 — Workbench Action F0

**Goal:** first useful attended replacement for generic repo editing / Desktop Commander for source work.

Preferred ownership: existing Workbench/Business auth + common executor + source/workspace owners; new sibling package only where the current owner map requires an adapter.

### Proposed tool contract

`prepare_project_action`

Input: approved `project_ref`, requested capability class, expected source identity when required. Output: opaque action ref, exact target/source/preimage, allowed operations, expiry, host/workspace identity. No mutation.

`apply_text_patch`

Input: action ref, relative path, expected SHA/absence, bounded patch. One write. Immediate descriptor-based readback and output SHA. Path/root/symlink/identity drift refuses.

`run_project_command`

Input: action ref, reviewed command recipe or closed argv, bounded args. Fixed selected-project cwd; closed environment; bounded time/output/concurrency; physical completion tracked past caller timeout; descendants bounded. Actual exit code preserved, including intentional non-zero test cases.

`read_action_result`

Bounded/paginated outputs and qualified artifacts, all bound to action/source/host identity.

`reconcile_action`

Read-only reconciliation after lost reply. Resolve `NOT_APPLIED | APPLIED | EFFECT_UNKNOWN` from owner-native receipts. Never replay.

### F0 test journey

On a disposable project/worktree:

1. prepare exact action;
2. create a file;
3. read/verify it;
4. patch it with expected preimage;
5. run one exit-0 command;
6. run one intentional exit-7 command and preserve `7` rather than labeling transport failure;
7. paginate output;
8. simulate lost caller reply after possible effect and reconcile without duplicate execution;
9. refuse outside-root, wrong principal, wrong host, stale boot/source, stale preimage, symlink/path swap, unauthorized command, secret/env request and expired action;
10. close/drain with zero orphan process and clear effect state.

### F0 non-goals

No arbitrary shell, direct protected-master write/merge, browser control, credential read, package-manager/root escalation, outbound network, Executive lifecycle fabrication or alternate-host failover.

Later capability recipes may be added only after evidence; do not start F0 as an omnipotent terminal.

## Wave X0 — end-to-end environment canary

Run after W0/W1/A0/H0/S0 have real accepted implementations.

### Web CEO journey

A fresh approved Web CEO:

1. loads current Navigator/procedure;
2. receives boot packet;
3. identifies an approved disposable project;
4. reads one file through Workbench Read;
5. edits it and runs a bounded command through Workbench Action;
6. opens/foregrounds the exact bound ChatGPT test conversation through Web-Sol;
7. delegates or routes one next action through the existing lifecycle/dialogue owners;
8. receives/reconciles result evidence;
9. leaves correct durable source/effect state.

### Native operator journey

A fresh native operator:

1. receives the same owner/surface map;
2. proves exact assigned operation/source/worktree/host;
3. uses CodeIntel/GitHub as appropriate;
4. performs bounded local project work;
5. returns exact patch/test/command evidence;
6. survives one transport/process restart without reauthentication or effect replay.

### Fault matrix

Inject at least:

- Executive connector unavailable;
- browser realm logged out vs service-worker restart;
- stale RuntimeBinding;
- duplicate-looking conversation;
- Workbench token expiry/revocation;
- project source movement;
- lost write/command response after possible effect;
- host disconnect;
- stale boot generation;
- provider lane degradation;
- domain plugin unavailable;
- active source-path collision.

Expected behavior is typed degraded/refusal/reconciliation, not hidden fallback or a second authority plane.
