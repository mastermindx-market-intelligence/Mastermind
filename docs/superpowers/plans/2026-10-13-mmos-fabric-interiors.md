A separate optional direct-Fabric inspector consumes installed status-v1 through `RawClient.readAttendedFabric` / `MissionHost.readAttendedFabric`. It requires existing signed-in acquisition permission and identity invalidation; rejects mismatched run/root, stale replies and invalid acceptance tuples; strips unknown fields and controller content; and reads only on explicit inspection. It creates no requests, workers, acceptance, polling, retries or private content store. When the default client supplies no reader, the UI says so and does not register an authentication observer or claim an idle fleet.

**Default web and native clients are not connected to a direct Fabric producer.** The optional interface is not an authenticated server implementation. Existing PR #1359 owns the machine-owner Fabric facade. Its trust model does not authenticate individual OS browser users or roots.
