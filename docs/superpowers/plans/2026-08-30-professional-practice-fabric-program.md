## 1. Central mission

Make Mastermind capable of assembling the smallest sufficient AI professional team for a Chairman
outcome, binding exact professional method and exact tool/effect ceilings, producing tangible
professional artifacts before build, independently evaluating craft, and learning from real outcomes
without creating a second hierarchy, capability system, lifecycle, memory or scheduler.

The first falsifier is Product / Experience Design. The program earns expansion into Security, Quant,
Research, Data Science, Growth or other practices only after the generic contract and at least one
real vertical show measurable advantage.

## 2. Program laws

Every wave obeys:

1. current protected Mastermind and same-SHA Skillpack procedure are reloaded before modification;
2. `COGNITION_ROUTE: CHAT_PRO_DEFAULT` remains the Sol-class default unless a complete approved
   metered exception exists;
3. Executive OS remains Job / Attempt / Worker / Event lifecycle authority;
4. Agent OS remains durable workstream / decision / discovery / handoff authority;
5. GitHub remains implementation and immutable evidence truth;
6. SessionTargetRegistry / RuntimeBinding and Wake retain exact surface and attention ownership;
7. Capacity Fabric / Model Router retain model/provider/account/surface eligibility and placement;
8. existing Executive capability policy / Sol Capability Fabric remains the only Skills/MCP/plugin/
   sandbox/effect-grant substrate;
9. practice, responsibility, model, surface, capability profile, artifact and evaluator remain separate
   identities;
10. one independently useful capability or one explicit records-only source-law slice ships per PR;
11. professional artifacts precede expensive implementation when late defect discovery is material;
12. builder and independent auditor remain separate for consequential work;
13. real production proof and outcome measurement remain distinct from CI, merge and installation;
14. no wave inherits START, capacity claim, receiver or modification authority from this program;
15. no super-skill, practice database, persona registry, duplicate router, transcript memory or
   permanent one-role-one-agent fleet is created.

## 13. `PPF-DESIGN1` — real Product Design A/B

### Target selection

Current archaeology selects one real, bounded, high-value Mastermind surface with representative
real data, a measurable primary task, reversible canary path and no overlapping active redesign.

### Arms

```text
A  generalist Project Sol -> implementation -> ordinary functional review
B  generalist Project Sol -> implementation -> independent Design Audit
C  Product Design pack -> qualified selector -> implementation -> the same independent Design Audit
D  C + accepted Figma/visual toolchain, only if FIGMA1 is proven
```

A->B isolates the audit increment, B->C the professional-method increment, and C->D the toolchain
increment. A reduced arm set must record which effects remain confounded.

### Implementation sequence

1. freeze common outcome, constraints, fixtures and budget rules;
2. create isolated independent first-pass carriers;
3. produce complete arm-specific pre-build artifacts;
4. blind/pairwise selection and record dissent;
5. implement isolated canary variants;
6. run deterministic and independent professional audit;
7. expose real users/Chairman to bounded comparison where safe;
8. link real task outcomes and full cost;
9. issue promotion verdict;
10. close carriers and update durable records.

### Stop conditions

- missing primary-task or real-data fixture;
- current target collision;
- non-comparable arm scope/budget without explicit adjustment;
- selector/auditor independence failure;
- unsafe production canary;
- outcome not measurable enough to justify a conclusion.

A specialist screenshot preference is not a pass. The new user capability and cost-adjusted outcome
must be explicit.

## 16. `PPF-FLEET1` — bounded multi-practice interval

### Mission

Operate several independent real projects through at least three accepted professional practices
without Chairman session hunting, generic overstaffing or hidden quality regression.

### Proof interval

Measure:

- professional coverage precision and missed-practice incidents;
- session/agent count versus minimum sufficient topology;
- artifact completeness before build;
- late professional rework;
- independent audit findings;
- product/machine outcome improvement;
- time, token and tool cost;
- Chairman interventions and preference requests;
- practice/model/tool composition performance;
- closeout and recovery by a fresh Sol.

### Cutover rule

Specialization becomes the normal path only for mission classes where evidence shows positive value.
Generalist work remains generalist. Unproven practices remain source-only or shadow. Failing practice
compositions are revised, narrowed or retired rather than protected by organizational prestige.
