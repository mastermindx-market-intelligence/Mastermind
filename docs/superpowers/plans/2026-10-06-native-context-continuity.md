## 4. Full environment contract

A principal startup must establish five independently observable layers:

1. **Procedure:** protected repository/commit, compatible INDEX, COLD_START, ACTIVE_EXECUTION, SESSION_RELIABILITY and relevant domain/delegation procedures from the same commit. A materialized but unread file is not loaded proof.
2. **Mission knowledge:** exact current directive, WS/operation, canonical context bundle, cumulative checkpoint, accepted decisions, evidence refs, rejected approaches, do-not-redo, unsettled effects and next action. Agent OS prose remains evidence, not authority.
3. **Role method:** principal, operator and leaf receive different scopes. Principals can synthesize/adjudicate; operators coordinate only their admitted descendants; leaves get a complete bounded task and minimum relevant facts. Do not weaken sealed leaf no-extension/no-MCP boundaries to imitate a principal.
4. **Tool capability:** actual native catalog and an authorized read canary; distinguish exposed, authenticated, admitted, usable and unprobed. Skills describe workflows; they do not supply missing OAuth, tools or permissions. No native skill attestation from a file existing on disk.
5. **Continuation:** one canonical checkpoint and current execution binding; exact result return and parent consumption; retained work after native interruption. No transcript database and no blind replay of unknown effects.
