## Product decision and DONE_WHEN

Adopt Paperclip's useful **goal → team → role → work → result** mental model *inside the existing Mastermind owners*, not its standalone server, database, heartbeat queue, model/account router, or independent agent identity. The Chairman should see a coherent organization, understand who owns an outcome and why, assign work through the original authenticated path, and follow one real Hermes-to-Fabric-to-original-parent result through both success and interruption. A source diagram, synthetic fixture, merged PR or green CI is not that end-state.

The existing true owners are:
- **Strategic direction:** Chairman and protected strategic state; **organization decisions/goal context:** Macro Agent OS workstreams and handoffs; **deep plan:** versioned Markdown with accepted IDs.
- **Authoritative execution:** Executive OS Job/Attempt/Worker, immutable scope/identity, effect and parent consumption; **placement:** Capacity/Subagent Fabric; **model quota/cost:** incumbent router and metering owner.
- **Persistent cognition:** the selected Hermes native session, memory and reviewed skill promotion; **company view:** existing authenticated Mastermind OS/Control Room composition.
- **Source/release:** GitHub; **transport/attention:** existing Slack/Secretary/wake boundary. No second company record store or new dispatch verb.
