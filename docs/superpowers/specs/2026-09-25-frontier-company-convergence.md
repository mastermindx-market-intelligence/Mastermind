No browser access, mode switch, provider turn, activation or persistent state.

Named consumer: the incumbent Web-Sol exact-session observation/closed-mode adapter under #836 after its writer and protocol gates clear. The existing protected background validator reserves selected_model/selected_effort/served_model/model_evidence as null; this candidate does not widen that public contract.

The pure async API `qualifyModeReadback(request, observations, nowMs)` consumes exactly two bounded JSON-derived observations, validates matching incumbent RuntimeBinding id/generation/fingerprint and document_epoch, requires sequential fresh observations after the caller's mode barrier, verifies SHA-256 integrity of the normalized flat observation, and qualifies the same selected family/effort twice. Missing, ambiguous, disabled, unauthenticated, active/unknown generation, stale or mismatched evidence fails closed. A second pure async API, `observeOpenModePicker(documentLike)`, reads only an already-open reasoning picker: exactly one visible reviewed slider container, one slider ARIA range/current value, its owned description, and exactly one checked family radio row. It emits only closed English first-canary family/effort evidence, sanitized cardinalities/slider state and a digest. It performs no click, keyboard, focus, network, storage, send or timer operation and is not wired into the extension manifest. A third pure API, `planModeTransition(request, pickerObservation)`, consumes only the sanitized picker observation. For the first canary it supports **same-family effort transitions only** (not model-family changes), returns either `NO_CHANGE`, a closed `SET_EFFORT_VALUE` semantic plan, or a typed refusal, and always keeps `action_authorized=false`, `browser_mutation_performed=false`, `readback_required=true`, and `capability_reprobe_required=true`. It exposes no selector string, DOM node, click/type primitive, URL, account data or served-model claim.

Requests and observations are closed shapes. Family selection is SOL or LATEST; requested effort is EXTRA_HIGH or PRO. These are selector selections, not provider-served identities. Observation digests include all flat fields except selector_evidence_digest, with lexically sorted keys and compact JSON. Maximum request/evidence lifetime is 30,000 ms; it is a candidate observation-freshness bound, not a session deadline, provider limit or policy admission. No clock, sleep, retry, network or DOM call is inside the reducer.

All results keep action_authorized=false, capability_reprobe_required=true and served_model=null. MODE_READBACK_MATCH means only qualified selector evidence. Integrity hashes are not authentication: the native owner must separately authenticate the producer and revalidate current authority/effects before any action. Unknown/malformed input is not echoed. Tests cover identity changes including A→B→A document epochs, tampered hashes, stale/future/replayed evidence, duplicate controls, denial/command-field injection, selected-family mismatch and immutable no-authority results.
