# Original ProjectExecution input in project help

The existing `executive_project_help` read can return
`mastermind.coo_project_help_result.v2` for an explicitly enrolled original
ProjectExecution root. This variant is read evidence. It keeps
`execution_authority=false`, `native_origin_attested=false`, and the actual
PARTIAL Mission / unobserved dispatch diagnostics.

The installed Control factory captures an optional
`ProjectExecutionInputReadOwner` from its original service, Runtime, namespace,
app binding, Supervisor and original retained-input owner. Help first proves
its current enabled COO enrollment and independent Workspace permission. It
then compares the actual retained adopted-plan bytes and existing parser's
contract with the current Plan/adoption and source-enrolled selector. A path,
context digest or supplied result object cannot replace this read authority.

`original_execution` records separate original-source, input-reference,
artifact, payload and context digests; the exact original source-plan tuple;
and the observed equality of actual retained/current adopted bytes. It omits
the private request, prompt, files, paths and credentials. Missing input,
changed adoption, foreign source, owner rotation or late permission loss
withholds the qualified result. The original before/after source and avenue
brackets, 25-second private read cap, individual source caps and owned
cancellation/drain behavior remain in force. A Python deadline cannot preempt
an operating-system syscall.

The independent Workspace resource v1 still reports retained input authority
unavailable and current adoption unobserved. It has no Executive input owner.
Generic Mission/action qualification still rejects this resource-scoped
PARTIAL receipt. An input witness is not a selected-child grant, placement,
delivery, parent consumption or acceptance.

Legacy help v1 output and omitted-reader behavior are unchanged. The existing
source-bound T3 API and packaged Hermes tool/memory consumers accept the
explicit result variant through their shared closed decoder. Source support
does not activate a profile or enroll a live session.

Qualification uses disposable actual Git/create/adopt/ProjectExecution,
Runtime, retained artifact and namespace owners. The signed API tests run the
real SDK/App/auth chain with an explicit same-process private hop. The packaged
Hermes test reaches its original source importer, native context tool and
memory prompt-delivery boundary. Their incumbent credential/source-seal,
physical worker/workspace-preparation and native PluginManager fixture edges
remain explicit. `tests/test_project_execution_help_ingress.py` is the separate
real Unix-Control replay for a host with AF_UNIX capability; it retains the
original admitting service and Supervisor and performs no worker dispatch.
