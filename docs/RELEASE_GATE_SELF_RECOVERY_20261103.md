## This bounded source delta

`control_plane/fabric_model_readiness.py` is a **pure, read-only prelaunch verifier**. It consumes a model-catalog witness supplied by an *existing*, authenticated host/provider owner; it does not call that provider or read credentials. It checks exact host/provider, bounded unique and valid IDs, explicit complete and source-verified evidence, timezone-aware timestamp (maximum five minutes old), and exact case-sensitive membership of the requested ID. It refuses missing/partial/stale/unbound catalogs or a model not in the catalog. It cannot authorize dispatch, retries, provider switch, leases, reviewer acceptance, GitHub approval or release, even when the model is listed.

The focused hermetic regression covers the observed `grok-4.7`-not-listed failure shape, positive listed-model evidence, cross-host mismatch, stale and future timestamps, incomplete/unverified catalog, forged/invalid IDs, and strict no-dispatch/no-retry semantics. No real provider was contacted; the fixture is deliberately *not* asserted to be today's actual Grok catalog.
