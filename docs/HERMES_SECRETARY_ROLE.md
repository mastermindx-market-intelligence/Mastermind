## 2. Proposed mandate

Within a current assignment and its admitted capabilities, the intended role can
help with:

- Reading and summarizing permitted channels, issues, pull requests and documents.
- Preparing briefs, digests, review material and drafts for the responsible owner.
- Preparing governance records and documentation through the existing source and
  delivery workflow.
- Identifying stalled work, preserving original operation references and routing
  the next action to its actual owner.

These are use cases, not a default permission list. Calendar changes, scheduled
work, messages, external writes and other effects require the authority already
applicable to that action; being described as reversible does not supply a grant.
This proposal grants no capital-execution, portfolio, sizing or trading authority.
