# Atelier Inbox

`Inbox` consumes the existing `mastermind.product_projection.v1` projection. Its
current coverage is one selected Mission. It creates no queue, attention store,
poller, command port, dismissal state or new priority order.

A current owner request requires a CURRENT Mission, an explicit recipient and
nonempty owner receipts whose `freshness` is `current`, the canonical lower-case
`executive_steward.Freshness` value. Execution failure, a returned result, review
or acceptance status never synthesizes a Chairman request. CEO/COO/worker turns
remain with their named seat. Missing attention is not a company-wide all-clear.

STALE requests may be inspected as retained history. UNKNOWN, UNAVAILABLE,
WITHHELD and UNASSOCIATED retain their labels without private request content.
Auth, exact selection/session/binding, Mission revision and source-state changes
unmount the evidence panel synchronously. Evidence inspection does not navigate,
rewrite the shell draft or change the selected operation. Escape returns focus
to its initiating button. Project navigation is an optional parent callback and
requires the exact resolved, unambiguous work/root pair.

The decision recommendation/preview remains unavailable: the current owner DTO
does not supply decision options or authority. EFFECT_UNKNOWN exposes original
operation reconciliation guidance with no replay, retarget or failover action.
Delivery, pickup, start, effect, return, review and acceptance remain separate.

Paper references: Mastermind OS file `01M3NRCX55B452A12819WNE1RH`, Canonical
Atelier AT04 `KY5-0` and AT04M `MNL-0`, token hash `fd2ed32e`. Desktop uses the
474:750 split with 48px gap, 44px Manrope heading and 30x36px detail-panel padding;
mobile uses a single column, 24px page padding and 32px heading. Illustrative
Paper decision copy is replaced by qualified owner data or explicit missingness.

This component is not yet registered in App navigation. Browser visual parity,
authenticated owner data, shell context preservation and installed acceptance
remain separate gates. No old route is removed by this source addition.
