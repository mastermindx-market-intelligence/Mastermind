# Accepted Direction and history

AT27 reads an explicit Agent OS association. A canonical workstream's
`accepted_direction` points to an indexed DEC carrying the closed
`agentos.direction_acceptance.v1` declaration for that same workstream.
The DEC's answer, rationale, actor and declared decision date supply the view.
An authored objective, generic decision citation, Git revision or S5 plan
adoption supplies none of those acceptance facts by inference.

`GET /workspace/project-direction/current?work_ref=WS:…` is a fixed observational
READ. The complete socket envelope and line delimiter share a 65,536-byte cap.
The installed collector issues the facade through the existing lower-core
binding after its nominal/source checks. Its isolated child captures the actual
Macro parser, Direction helper, plan helper and fixed WS/DEC bytes from one Git
revision inside the existing pre/post source seal. The Workspace adapter reuses
the current catalogue and permission owner, checks both before and after, and
requires the result's Macro revision to match that catalogue. It reads no Job
or Runtime state and performs no publication or provider/host action.

History follows explicit, reciprocal predecessor links. At most eight revisions
including current are returned; a remaining tail keeps the total unknown. The
declared decision date has DAY precision. A source commit identifies the read's
Git snapshot, not an observation time or a reconstructed acceptance event.

The panel acquires only on an explicit read and fences the result by reader,
selection, permission and source generation. Inspecting a previous revision
changes local selection only. The existing integrating conversation owner
supplies `onChangeDirection`; this panel sends no message and publishes nothing.
Dark and light use the existing shell materials and tokens. The shell owns
outer gutters; the revision list and inspector stack on mobile. Source checks
do not establish a rendered theme/locale/viewport matrix.

Prospective `ACCEPT_DIRECTION` authoring uses the existing fixed publisher and a
distinct real grant. The pure Macro recipe emits DRAFT_ONLY WS/new-DEC/optional
predecessor postimages. Its actor, original operation date and permission binding
come from that publisher, not public decision fields. An existing exact original
operation returns read-only reconciliation with no postimages; changed payload or
binding is a conflict. The helper writes nothing and never proves a grant or
Git publication. A Root-decided source record prepared through the normal
protected Git workflow is separate from any app or Runtime permission.
