## Start or reopen

Open the installed **Mastermind OS.app**. To resume existing work, choose **Projects** and the original project. Check its **Mission source** and execution observation before using its conversation or results. If the project catalogue or Mission is unavailable, retain the original project/request and follow the displayed source-state recovery. An unavailable source does not mean there are no projects or agents.

The project workspace keeps conversation and composer in stable slots while **Files** and **Details** are opened. Close a disclosure to return to its control. Project setup and conversation lists also expose their existing **Back to projects** and **Back to conversations** actions. This source behavior is not a fresh authenticated reopen receipt.

## Provider configuration and chat

In Office, **Configuration → Review connection** shows the existing operating-role configuration and its evidence. **Refresh configuration** reads through the incumbent owner when available. The panel is read-only: it does not accept API keys, enroll roles, change providers or prove the model that served a turn.

Use the installed **Conversations** or qualified project conversation. If the catalogue has not established the exact project/Mission association, project chat displays its unavailable state. Keep an unsent draft on its original identity and project; use the existing retained-draft recovery controls after authentication returns.

There is no verified installed DeepSeek/Hermes provider-switching journey in this receipt. DeepSeek's proposed remote origin is still a candidate. Hermes's proposed same-user native session is distinct from a remote web session. Do not infer either route from a configuration label.

## Project assignment and starting work

Select the intended existing project before opening **Start work**. Review the current project plan and the original goal, project and execution profile in the existing launch owner. Opening or reviewing a form does not start a worker. If an earlier request or draft is held, resolve that original item through its existing controls before creating another.

The installed source has no organization-chart action that assigns or enrolls a team. Configured roles, selected project, admitted work and executing Job/Attempt are separate facts. Full assignment and worker execution remain subject to S2/S3 real-path evidence.

## Find a result and return

For a qualified project, inspect its execution history and retained results through **Files**, or the existing **Overview / Work** result viewer. Open the retained result for the original job and attempt. A pending or unavailable read is not a completed result; a completed result is not parent or product acceptance.

Use the project workspace's existing Close/Back controls. The new O3 path into the external result viewer still owes preservation of selected work, query and return focus in S0's composition; do not assume that unshipped path is complete.

## Stop or correct

Edit an unsent draft in its existing composer. Cancel or close an unsent launch through the current launch controls when offered. For an active session, use only the **owner-provided Stop control**, which is offered when that current session supplies a stop label and authorization. There is no general organization-level Stop or restart action.

When the app shows **Previous request / Check status**, inspect that original request. Do not resend because a callback or result is missing. A correction after execution belongs to a newly reviewed action through the existing owner, not a relabeling of the retained result.

## Explicit unavailable states

| Visible state | Operator interpretation |
| --- | --- |
| Reading / pending | The existing read has not returned; no work count or completion follows. |
| Unavailable / not supplied | The necessary source or host capability is absent. Keep the original selection. |
| Stale / changed identity / denied | Earlier facts or controls cannot be reused as current authorization. |
| Partial coverage | Visible rows are only the observed subset; total agents and progress remain unknown. |
| Enrollment unverified | Configuration is not evidence of an enrolled session or available worker. |
| Original request held / effect unknown | Reconcile the same request; do not relaunch or switch carriers. |

## Recovery and rollback

Record the installed build identity, original project/request and visible error. Use the app's existing original-request status or draft-recovery controls when qualified. There is no operator-facing rollback button. S0 retains the existing bundle/release rollback path; this O3 source change did not install, restart or alter any backend.

The original protected installer/result hold and earlier Paper identity/Chrome credential refusals remain in force. This guide grants no new privileged result read, credential recovery, service restart or duplicate test turn.
