# Knowledge and bounded source reading

Canonical Paper file `01M3NRCX55B452A12819WNE1RH`, token hash `f3c5ac93`, supplies
AT05 `L0Z-0` / `MNM-0`, KD01 `SPU-0` / `STU-0`, and SA01 `T0U-0` / `T0V-0`.
Illustrative source names, counts, people, recommendations and access explanations
are design examples. They are never substituted for owner data.

Knowledge is mounted by App. Its evidence-reference search consumes only the
selected Mission's existing `mastermind.product_projection.v1` evidence fields.
A citation does not supply the cited record's content or establish direct Project
ownership. Decisions, discoveries, handoffs and contracts require their actual
owner indexes; selected Mission coverage is not a company-wide search index.

Original source navigation preserves the exact owner/ref/revision tuple. No URL
or destination is guessed. Missing content capability means unavailable content,
not proof of a permission denial or a source's absence. Historical qualification
stays historical, incomplete provenance stays unknown, and source clocks remain
separate from local acquisition time.

The source-reader composition uses the existing fixed `MissionHost` retained
result-list and exact-result ports. The existing `RetainedResults` component owns
its normalized selected-workspace request, independently decoded five-field
result selection, abort/epoch handling, partial catalogue coverage and bounded
response budgets. Result content remains an observation; reading does not record
acceptance or establish source freshness. Markdown is presentation of already
acquired text with inert links, HTML and image references. The exact text and
returned structured content remain available separately.

The optional original-draft companion receives the existing observed-conversation
owner explicitly. It qualifies the exact source selection, auth/context and
observed Mission association before displaying private draft text or offering
an insertion. Append and conditional Undo use the existing owner's expected
revision checks; newer user edits are preserved. No recipient, send authority,
persistence, new draft owner or lifecycle is created by this view.

Auth, target, binding, relevant source and host changes invalidate private reader
state. Returning from a source retains the current view's supplied-reference
query. A new scope starts clean. Source tests establish their tested frontend
behavior only; rendered parity, authenticated native reads, installation and
programme acceptance require their own evidence.
