# Knowledge source references

Current Paper visual references are AT05 `L0Z-0` and AT05M `MNM-0` in Mastermind OS
file `01M3NRCX55B452A12819WNE1RH`, token hash `fd2ed32e`. KL2 `JGE-0` governs
provenance and canonical ownership. Illustrative decisions, discoveries, names,
counts and artifact content are not used as live facts.

This read-only leaf consumes the existing `mastermind.product_projection.v1`
Mission evidence fields. It provides search, exact source context and a typed
navigation callback. No source is acquired, stored or changed. Evidence references
are explicitly distinct from the records they reference; decision, discovery,
handoff and contract indexes remain unavailable. A reference's presence in a
Mission establishes only that citation, not direct ownership by the Project.

Per-reference freshness can reduce Mission qualification. Partial or incomplete
provenance stays UNKNOWN; unavailable stays UNAVAILABLE; historical sources stay
STALE and are opened only as history. The optional navigation owner receives the
unchanged owner/ref/revision tuple; no URL or destination is guessed. Missing
navigation capability is visible and disabled. There is no generated summary or
canonical record content to promote.

Auth, target, session/binding, Mission revision and source-state changes clear
the private search/inspection state before rendering. UNKNOWN, UNAVAILABLE,
WITHHELD and UNASSOCIATED Mission projections do not expose retained references.
Escape returns focus to the invoking row, or search if that row was filtered out.

The leaf is not yet in App navigation. Source tests and builds do not establish
browser visual parity, a live Agent OS index, source opening, native installation
or Chairman acceptance. The old Evidence capability remains intact.
