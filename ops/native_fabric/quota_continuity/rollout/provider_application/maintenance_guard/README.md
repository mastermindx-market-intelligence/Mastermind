# Retain the frozen native maintenance source cohort

This optional composition belongs to the existing native APPLICATION builder.
It retains five provider payloads from protected commit
`2541a68e9240ca3fb5c1fda7b68e1df8984c973b` when advancing the complete
frozen `current116-maintenance-guard` source predecessor. The retained regular source files
are authenticated by SHA-256, byte count, original Git blob, and source path.
The original router-admission and maintenance-provenance records bind that
protected source. Tests are independent proof inputs, never runtime sources.

Build through the incumbent owner:

```sh
python3 -B ops/native_fabric/quota_continuity/rollout/build_review_stage.py \
  --output /absolute/new/review-stage \
  --include-provider-plan-application \
  --include-provider-plan-remote-placement \
  --include-provider-plan-maintenance-guard \
  --include-go-application --include-application-http --include-application-glm
```

The optional step replaces exactly five provider payloads after the existing
remote-placement composition and before the existing GLM core transformation.
Every other target payload remains byte-identical to the same build without
the option. The Broker already contains the two exact protected maintenance
methods, and the executor already retains the sparse-index setting.

The complete predecessor manifest is
`3cf95195569cd80f0b978dd48160dda30baf68f48daab4d8d6d1b1f5c35e1ac1`.
The complete 116-member target base before GLM is
`4dccdb9401e27a38bba9153de5f82a23d1169aa204bac847887f6c9bc31a73be`;
after the existing GLM core transformation it is
`fd716e44b9ffba9567df2ea1120ef8f2bd52bd7cb244768078a44fe4b43db58e`.

The existing Go transition validator binds both directions: the selected
maintenance predecessor requires the retained target, and a different provider
predecessor cannot use that target. Complete source maps, staged payloads,
external-component dependencies, and original CURRENT compare-and-swap remain
mandatory. Partial cohorts, changed retained bytes, foreign additions, source
symlinks, and either cross-cohort direction fail closed. H2 remains explicitly
incompatible with remote placement; this composition does not qualify H2.

Building or publishing this source does not select a native generation, forward
an account, install Hermes, grant a service, or prove a provider turn.
