# Observe an original ordinary artifact run

Ordinary GLM/Qwen artifact runs already retain a validated PRE_LAUNCH binding,
packet contract, immutable support manifest and original account allocation.
The existing observation command could use these only for named historical runs.
This candidate adds an explicit `--parent` option to that same command:

```
python3 <installed fabric_task.py> observe-run <original-id> --root <verified-original-root> --parent <verified-assigning-parent> --destination <new-private-evidence-directory>
```

The actual assigning parent invokes it. The supplied parent must match its native
identity and the original launch/packet; the original broker row must match root,
host, pool, account and model. Current host registration and code manifests are
checked. Mutable native labels remain correlation, not authentication or a new
grant. A native child preserves its commissioned original root and budget.

The existing fixed read transport verifies the remote original packet and code
closure, then reads only the run marker, return code, stdout metadata and recorded
process receipt. It never reads stdout contents, probes `/proc`, accepts a result,
changes a lease, cancels, launches or substitutes a worker. Missing files do not
prove death or retry authority; a marker or file size does not prove useful work.
Existing default calls and every historical scope stay unchanged. No per-run
allowlist entry is added. Old plaintext, unsupported producer generations,
unknown/refused controller evidence and foreign parents remain unqualified.

Source qualification and normal protected release precede installation. Install
only the three exact candidate files over the recorded preimages. The adapter
hash changes its pinned Stop-hook definition, which needs the user's normal
review/trust; foreground observation does not depend on hook attention. Existing
permission refusals remain binding: this capability never authorizes replaying a
refused read through a newly admitted route. The motivating App worker and all
other live workers retain their original assigning parent and controller.

Validation:111 affected inert checks pass against the actual candidates. The
legacy test loader gained an optional source directory so its unchanged cases
exercise installed/candidate bytes rather than accidentally testing its old copy.
One independent read-risk review is pending. No original App remote observation
or worker effect has been performed by this source author.
