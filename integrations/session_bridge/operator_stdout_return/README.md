# Original stdout-only operator delivery

A restarted original controller can leave an operator's retained stdout unavailable
to its assigning parent. The artifact collector cannot recover that response: this
original operator was commissioned to return a stdout patch, with no artifact
production contract. This finite profile joins its original private packet and
launch log to a nonsecret historical projection from the existing operator owner.
It does not renew a bearer, authorize children, settle leases, alter the controller,
record acceptance, or create a new dispatcher.

Scope is exactly `rf-codegen-contracts-impl-01a1333c-v1`, original root
`01a1333c-a475-7052-95a8-72a88eb8c17b`, assigning native parent
`01a1333e-742d-7c80-8dbb-db42109f06ce`, and original Ubuntu2 route. The
parent is bound by the independently verified original commission; the operator
grant does not contain it. Environment checks correlate the caller with that
commission and are not authentication.

The existing `capsule-artifacts` adapter entry selects this exact profile. One
fixed fresh evidence directory prevents a second read by choosing another path.
The same held-file transport checks RC, one strict process receipt and stdout.
COMPLETE requires rc0, matching stdout digest and length, complete capture and
proven process cleanup. Lease, child and original controller settlement stay
UNKNOWN. `collection-result` consumes only the exact COMPLETE receipt and
verified chunks. A refused, partial or nonzero response is retained without
acceptance, inferred death, mutation, or retry permission.

The two zero-context patches apply with `git apply --unidiff-zero` only against
the exact preimages in SOURCE_MANIFEST.json. `original_delivery_collector.py`
elsewhere in this PR also gains typed diagnostics for its own six-field refusal
envelope; the remote reader and guards are unchanged. The shared publisher now
clears delivery/terminal flags when invalidating a failed publication.

Source verification uses 11 historical-binding tests and 28 additional profile
and diagnostics checks. Fixtures are private and inert. The latter include the
already-retained R2 refusal envelope as offline evidence; they never repeat that
read. The original R2 and Research Vault collection refusals remain frozen.

Installation and any actual original-parent delivery are separate evidence in
SOURCE_MANIFEST.json and the existing program records. Native authenticated
Executive admission, RuntimeBinding and idle Wake are separate obligations.
