persistent web-session carrier. Paid-service quiesce descriptors belong to their
own closed operation and cannot be repurposed.

The finite reader does not change that behavior. The next security slice belongs
in the existing RemoteAccess/Gateway/route owners, with a trusted association
restriction that cannot disappear merely because a reader port closes.

## Native UI and ACP command join

The donor has real pre-bootstrap transport hooks. Install both unary `rpc.call`
and `rpc.open` before native Connection mounts, preserve its generation recovery,
and prevent fallback to stock owner HTTP/WebSocket. The separate file-upload
carrier and non-owner access baseline also need the same qualified composition.
The original composer, request IDs, pagination, session references and streaming
reducers remain the owners.

Stock ACP can run on an inherited stream in the existing Context, but it cannot
adopt an already-live web Agent. Its private session map is populated by its own
create/resume paths, and resume refuses an already-live session. ACP prompt does
not automatically preserve the web requestId, while its cancel behavior differs
from web `keepInbox:true`. Mounting another loop would not close this join.

Authenticated Send/resume/Stop must therefore retain one original operation,
native session/Agent and streaming owner through the incumbent Executive/ACP
contracts. Same-key changed input must refuse. Interrupted submission cannot
resend. Stop ACK must remain distinct from terminal-turn proof. Native attachments
cannot be silently dropped or smuggled through the bounded text-only Send field.
