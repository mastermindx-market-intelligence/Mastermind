## Native path coexistence

Ordinary CLI resolution emits the existing `source=host_bound` marker. The
native gateway now preserves it through its runtime projection and carries it
on the turn route, outside constructor kwargs. A marked route must pass the
registered profile/runtime checks and claim its original native admission before
the attended plugin can bind the APPLICATION owner.

The held secretary/meta-CEO host supplies no attended marker. It retains its
existing wrapper, constructor, original LiveSession capability and publication
checks. It does not enter the attended hook or consume a second provider claim.
A marker never substitutes for original native authorization.

The current qualification includes the real resolver, both projections, original
SQLite admission, native constructor and one loopback conversation. It also
checks that an unmarked role route does not enter the attended owner and that a
marked invalid profile refuses before a claim or factory. The old synthetic
route fixture alone could not establish these properties.
